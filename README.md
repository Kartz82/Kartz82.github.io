# Kartikeya Vemula Portfolio

Vite + React + TypeScript + Tailwind CSS portfolio foundation deployed with GitHub Pages.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis

## Local Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

GitHub Pages deployment runs from `.github/workflows/pages.yml` and publishes the Vite `dist` output.
